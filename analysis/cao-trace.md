# 조조 데이터: 파일에서 장수정보 화면까지

대상: 제공된 Ekd5.exe 1.0.6.6. 분석일: 2026-10-22.

이 조사는 게임을 실행하지 않고 사본 바이트, REA/Ghidra 코드, 화면 리소스를 대조한 정적 분석이다. 아래 표시값은 초기화 경로에서 도출한 값이며 실제 세이브 화면을 캡처한 결과가 아니다.

## 결과

조조는 Data.e5의 0번 내부 항목에 있는 첫 번째 32바이트 레코드다. 파일 오프셋은 0x18C, ID는 0이다. 이 항목은 32,768바이트, 즉 1,024명 × 32바이트다.

기본 능력치 표시값은 무력 82, 통솔 98, 지력 92, 민첩 80, 행운 84다. 병종 코드 0은 이 실행 파일에서 ‘군웅’을 가리킨다. 초기 레벨은 1이며 HP 기본 파라미터는 110, MP 기본 파라미터는 30이다.

## 1. 원시 레코드

```text
Data.e5, 내부 항목 0, 레코드 ID 0, 파일 오프셋 0x18C
c1 b6 c1 b6 00 00 00 00 00 00 00 00 00 00 00 00
00 ff 29 31 2e 28 2a 6e 00 1e 00 01 00 ff ff ff
```

앞의 C1 B6 C1 B6는 CP949 ‘조조’다. 추출한 0번 항목 전체가 사본 Data.e5[0x18C:0x818C]와 바이트 단위로 일치한다. 원시 비교와 이웃 무장의 데이터는 output/cao-raw.json에 있다.

## 2. 파일 로딩과 내부 주소

FUN_0041b666은 0x496F60에 저장된 포인터를 입력 버퍼로 사용해 FUN_0041b51e("DATA.E5", 0, inputBuffer)를 호출한다. 이어 ID 0..1023을 순회하며 FUN_004061e4로 내부 구조체 주소를 구하고, FUN_00408c0c로 한 명을 초기화한다. 초기화 함수는 다음 입력 레코드인 source+0x20을 반환한다.

단일 무장 재초기화 함수 FUN_0041b617도 inputBase + id*0x20을 명시적으로 사용한다. 따라서 32바이트 간격은 이름 배열만으로 추측한 값이 아니다.

FUN_004061e4의 어셈블리는 ID에 0x48을 곱하고 [0x4CEA00]을 더한 결과를 ECX에 남긴다. 내부 구조체 주소는 [0x4CEA00] + id*72다. 0x4CEA00은 포인터를 저장한 위치이며 구조체 자체의 고정 주소가 아니다. 이 함수의 의사 코드는 레지스터 결과를 생략해 빈 함수처럼 보이므로 어셈블리를 확인했다.

## 3. 32바이트에서 72바이트로 변환

FUN_00408c0c는 내부 구조체 72바이트를 0으로 채우고 ID|0x1000을 첫 4바이트에 저장한다. 아래 source 오프셋은 파일 레코드 기준, unit 오프셋은 내부 구조체 기준이다.

- 이름: source+0x00의 12바이트 → unit+0x08. 이어 이름 보정 함수를 호출한다.
- 얼굴 관련 초기 코드: source+0x0D의 uint16 LE → unit+0x04 및 무장별 캐시. 조조는 0이다.
- 다섯 기본 능력 저장값: source+0x12..0x16의 uint8 → unit+0x21..0x25.
- 같은 다섯 값을 uint16으로 확장해 unit+0x11, +0x13, +0x15, +0x17, +0x19에도 복사한다. 이 복사본의 모든 전투 용도는 이번 조사에서 확정하지 않았다.
- HP 기본 파라미터: source+0x17의 uint16 LE → unit+0x1B. 초기화 상한은 500이며 조조는 110이다.
- MP 기본 파라미터: source+0x19의 uint8 → unit+0x1F. 초기화 상한은 250이며 조조는 30이다.
- 병종: source+0x1A → unit+0x2B. 조조는 0이다.
- 레벨: source+0x1B → unit+0x2C. 0이면 1로 바꾼다. 조조의 원시값은 이미 1이다.

source+0x0C, +0x0F, +0x10, +0x11, +0x1C..0x1F의 정확한 게임상 의미는 아직 확정하지 않았다. 넓은 메모리 복사 명령만으로 각 필드의 자료형 전체를 단정하지 않았다.

## 4. 기본 능력치 화면 표시

장수정보 화면의 FUN_004784f6은 index 0..4에 대해 FUN_004070e1(unit,index,1)을 호출하고 결과를 SetDlgItemInt로 컨트롤 0x7D1+index에 보낸다.

FUN_004070e1은 unit+0x21..0x25 중 해당 바이트를 읽는다. 마지막 인자가 0이 아니면 왼쪽으로 1비트 이동하므로 표시값은 저장값의 두 배다.

실행 파일 대화상자 리소스 166 (‘장수정보’)에서 같은 행의 라벨을 대조했다.

- 무력: 파일 0x19E, 원시 41(0x29) → unit+0x21 → 82, 컨트롤 0x7D1.
- 통솔: 파일 0x19F, 원시 49(0x31) → unit+0x22 → 98, 컨트롤 0x7D2.
- 지력: 파일 0x1A0, 원시 46(0x2E) → unit+0x23 → 92, 컨트롤 0x7D3.
- 민첩: 파일 0x1A1, 원시 40(0x28) → unit+0x24 → 80, 컨트롤 0x7D4.
- 행운: 파일 0x1A2, 원시 42(0x2A) → unit+0x25 → 84, 컨트롤 0x7D5.

별도의 장수선택 화면 FUN_0045c697도 같은 getter를 마지막 인자 1로 호출하고 컨트롤 0x3F8..0x3FC에 표시한다. 대화상자 리소스 236의 라벨도 같은 순서다.

## 5. 이름·병종·레벨·HP/MP의 소비 경로

이름 getter FUN_00407775는 unit+0x08부터 읽어 표시용 unit+0x37에 복사한다. FUN_00478664는 그 결과를 SetDlgItemTextA의 컨트롤 0x3F6에 넘긴다.

병종 getter FUN_00406610은 unit+0x2B를 읽는다. FUN_0040111a의 어셈블리는 그 값(EAX)으로 0x48BEA8의 포인터 테이블을 조회한다. 코드 0은 첫 포인터 0x5000D0을 가리키며 해당 주소의 원본 파일 위치 0xD18D0에 CP949 ‘군웅’이 있다. 장수선택 화면은 이 문자열을 컨트롤 0x475에 표시한다.

레벨 getter FUN_004065d0은 unit+0x2C를 읽어 장수선택 화면의 컨트롤 0x3F7로 보낸다. 장수정보 화면도 같은 오프셋을 읽어 0x3F9에 표시한다.

HP getter FUN_00407263은 unit+0x1B, MP getter FUN_0040728f는 unit+0x1F를 읽어 추가 보정 함수를 호출한다. 장수선택 화면은 HP/MP 라벨과 연결된 컨트롤 0x3FD/0x3FE에 결과를 보낸다. 따라서 110/30의 HP/MP 관련 의미는 확인했지만, 추가 보정·성장·장비·상태 등을 반영한 최종 값 또는 현재 HP/MP라고 단정하지 않는다.

## 근거와 재현

output/cao-trace.json에 각 필드의 파일 오프셋, 자료형, 원시값, 내부 오프셋, 화면 컨트롤, REA Evidence ID를 기록했다. 완전한 근거 묶음과 관측 스냅샷은 output/rea-cao에 보관한다.

- 전체 로딩: data-caller-41b666.json.
- 초기화: unit-initialize.json.
- 내부 주소와 단일 레코드 주소: unit-runtime-address.json, unit-single-reset.json.
- 능력치 getter/표시: unit-get-basic-attribute.json, unit-info-basic-attributes.json, unit-select-basic-attributes.json.
- 이름·병종·레벨·HP·MP: unit-get-*.json, class-get-name.json.
- 라벨/컨트롤: output/unit-dialogs.json.

프로젝트 루트에서 다음을 실행하면 저장된 근거와 사본으로 결과를 재현한다. 게임 실행이나 새 Ghidra 분석은 필요 없다.

```powershell
node analysis/scripts/cao-raw.mjs
node analysis/scripts/unit-dialogs.mjs
node analysis/scripts/trace-cao.mjs
```

세이브 로딩, 시나리오 명령, 성장, 장비와 상태 효과가 초기화 이후 값을 바꾸는 경로는 별도 조사 대상이다. 이번 결과는 제공된 1.0.6.6 파일 기준이다.
