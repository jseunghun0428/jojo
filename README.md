# 철령전기

철령전기는 React, Phaser 3, TypeScript, Vite로 만든 브라우저용 2D 턴제 전략게임입니다. 전장과 장수는 Phaser의 도형으로 그렸습니다.

## Windows에서 실행하기

가장 빠른 방법은 탐색기에서 `start-game.cmd`를 더블클릭하는 것입니다. 필요한 패키지를 처음 한 번 설치하고 브라우저를 엽니다.

VS Code에서 실행하려면 아래 순서로 진행합니다.

1. VS Code에서 **파일 → 폴더 열기**를 선택하고 이 README가 들어 있는 **iron-pass** 폴더를 엽니다.
2. **터미널 → 새 터미널**을 선택하고 아래 두 줄을 한 줄씩 실행합니다.

   ```powershell
   npm.cmd ci
   npm.cmd run dev
   ```

3. 터미널에 나온 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)을 브라우저에서 엽니다. 게임을 끝낼 때는 터미널에서 **Ctrl+C**를 누릅니다.

처음 실행할 때 Node.js 22.12 이상(22.x) 또는 24 이상이 필요합니다. 터미널에서 `node --version`으로 확인할 수 있습니다. Node.js가 없는 PC에서는 [Node.js 공식 다운로드](https://nodejs.org/en/download)에서 LTS 버전을 설치하고 VS Code를 다시 엽니다. `npm.cmd ci`는 처음 설치하거나 패키지 구성이 바뀌었을 때 실행합니다. 이후에는 `npm.cmd run dev`로 시작합니다.

## 첫 전투부터 상점까지

- **추천 편성 → 첫 전투 출전**을 누르면 장수 4명과 총대장 조조로 시작합니다. 직접 편성할 때는 코스트 10 안에서 장수를 선택한 뒤 총대장을 지정하세요.
- 지도에서 행동 전 장수를 선택하면 파란 이동 범위가 표시됩니다. 파란 칸 위에 마우스를 올리면 이동 경로가 나타납니다. 도착 칸을 클릭하거나 장수를 다시 클릭해 제자리에 머무르면, 붉은 공격 범위와 **공격·책략·도구·대기** 명령이 표시됩니다. **공격**은 범위 내 적에게 물리 공격을 하고, **책략**은 화계 같은 책략을 선택한 뒤 대상에게 사용합니다. **도구**는 보유한 회복 아이템을 보여 줍니다. 방향키와 Enter로 지도에서 칸을 고를 수 있고, Esc로 명령을 취소할 수 있습니다.
- 장수마다 턴당 한 번 이동할 수 있습니다. 공격, 화계, 회복 아이템, 대기 중 하나를 실행하면 해당 장수의 행동이 끝납니다. **아군 턴 종료**를 누르면 적군이 움직입니다.
- 적군을 모두 격파하면 **보상 받고 상점으로**를 누릅니다. 야영지에서 장수, 보물, 회복 아이템을 구매할 수 있습니다. 영입한 장수를 데려가거나 보물을 장착하려면 **출전 편성**을 엽니다. 준비를 마치면 **다음 전장 출전**을 누릅니다.
- 총대장이 쓰러지면 **같은 전장 재도전**으로 같은 맵과 적 배치에서 시작합니다. 다음 전장과 재도전 모두 HP와 MP가 완전히 회복됩니다. 전투에서 쓴 아이템은 소비됩니다.
- 진행 상황은 현재 브라우저에 자동 저장됩니다. 같은 주소에서 새로고침하거나 다시 열면 이어집니다.

## 원정 규칙

- 코스트는 최초 편성에만 적용합니다. 장수는 영입 인원 제한 없이 보유할 수 있고, 총대장을 포함해 최대 12명이 출전합니다. MVP에는 편성 및 영입이 가능한 장수 52명과 보물 24개가 있습니다.
- 각 전장의 맵과 적 편성은 고정되어 있습니다. 총 50개 전장이 10개 기본 지형의 변형과 고정 적 진형으로 구성되어 있습니다.
- 승리할 때마다 미영입 장수와 미보유 보물을 각각 최대 5개씩 무작위로 제시합니다. 후보가 5개보다 적으면 남은 후보를 모두 제시합니다. 이번 상점에서 구매한 자리는 다음 승리 때 새로 갱신됩니다.
- 보물은 장수당 하나를 장착할 수 있습니다. 회복 아이템은 전투 중에만 사용합니다.

## 장수 병과와 능력치

기존 웹 원정은 12개 임시 병종을 사용합니다. 신조조전 원정은 원본 병종 번호와 이름, 장수 배정, 성장치, 이동력, 공격 범위, 지형별 이동 비용과 능력치 배율을 사용합니다. 신조조전 원정의 기본 HP·MP와 무력·지력·통솔·민첩·사기는 원본 장수 데이터에서 가져옵니다.

최초 편성, 상점, 출전 편성, 전투에서 아군의 무력·지력·통솔·민첩·사기·정치를 볼 수 있습니다. 무력·지력·통솔·정치는 삼국지 11을 참고했고, 민첩·사기는 철령전기 임시값입니다. 정치는 기존 무력·지력·통솔과 일치하는 시나리오의 값을 우선 적용합니다. 정치의 현재 용도는 장수 정보 표시입니다. [시나리오별 장수 능력치](https://kongming.net/11/appearances/) · [전체 장수 능력표](https://www.xycq.org.cn/forum/viewthread.php?authoruid=64339&tid=88974)

물리 기본 피해는 제공된 신조조전 7.0의 `ekd5.exe`에서 확인한 방식으로 계산합니다. 공격자 레벨 + 25에 보정 공격력과 방어력 차이의 절반을 더하며, 절반의 소수점은 0 방향으로 버립니다. 최소 피해는 1입니다. 물리 명중률에는 지형 보정이 적용된 순발력을 사용하고, 기본 반격 배율은 75%입니다.

공격력·방어력·순발력은 현재 장수 능력치, 레벨, 병종 성장치, 지형 보정으로 계산합니다. 기존 철령전기 공격·방어 보너스와 장착 보물의 수치도 사용합니다. 임시 지형 배율은 방패병이 일반 숲과 물에서 110%, 나머지는 100%입니다. 아군 레벨은 1이고, 적군은 10전장 단위로 1~5레벨을 사용합니다. 병종 상성, 방향·장비 특수효과, 피해 변동, 회심·2회 공격·책략은 7.0 원본과 대조가 더 필요합니다.

## 신조조전 원정

`iron-pass` 옆에 `jo` 폴더가 있으면 `start-game.cmd`가 최초 실행 때 원본 전장과 병종을 자동으로 가져옵니다. **추천 편성 → 첫 전투 출전**으로 영천 전투를 시작합니다. 화면 상단의 **기존 웹 원정**으로 기존 저장을 열 수 있습니다. 두 원정은 각각 자동 저장됩니다.

VS Code 터미널에서 가져오기를 다시 실행하려면 `npm.cmd run import:jo-game`을 사용합니다. 원본이 다른 곳에 있으면 `npm.cmd run import:jo-game -- "D:\Games\jo"`처럼 경로를 지정합니다. 전장과 병종을 가져오는 데에는 Node.js만 필요합니다.

원정에는 원본 순서의 첫 50개 지도, 지형, 출전 좌표와 적·우군 배치를 사용합니다. 총대장부터 원본 출전 칸에 배치하며 웹 출전 상한은 12명입니다. 영천 전투의 목표는 장보·장량 격파이며 유비·관우·장비가 2턴에 합류합니다. 다른 전장은 웹의 적 전멸 조건을 사용합니다. 원본 출전 위치가 같은 칸에 겹치면 한 유닛만 배치하며, 원본 각본상 아군 칸을 전부 적이 점유하는 사곡 전투에서는 인접한 빈 칸에 총대장을 배치합니다. 원본 책략·보물 효과와 나머지 이벤트는 후속 작업입니다.

## 개인 테스트용 그래픽

이 작업 폴더에서 개발 서버를 실행하면 `local-graphics/jo-assets`의 신조조전 초상화와 장수별 대기·이동·공격·피격 조형을 불러옵니다. 고유 조형이 지정되지 않은 유닛은 진영별 병과 조형으로 표시합니다. 대응 이미지가 없으면 기본 그래픽이 표시됩니다. 이 폴더는 개발 서버에서만 사용되며 배포 빌드와 프로젝트 ZIP에서는 제외됩니다.

다른 PC에서는 Git 저장소를 받은 뒤, 신조조전 7.0 원본 폴더를 `iron-pass` 옆에 `jo`라는 이름으로 둡니다. Python 3을 설치한 후 `iron-pass`에서 아래 명령을 실행하면 개인 테스트용 그래픽을 재생성합니다.

```powershell
python -m pip install "Pillow>=12"
npm.cmd run import:jo
```

원본 폴더가 다른 곳에 있으면 `npm.cmd run import:jo -- "D:\Games\jo"`처럼 경로를 지정합니다. 변환에 필요한 코드는 `tools/jo-assets`에 있습니다. 원본 파일과 변환 결과는 각 PC에 로컬로 보관합니다. 브라우저의 게임 진행 상태도 해당 PC에 저장됩니다.

## 테스트와 빌드

```powershell
npm.cmd test
npm.cmd run build
```

자동 테스트는 실제 첫 전투의 승리부터 구매와 2스테이지 출전까지, 초기 코스트, 50개 전장의 고정 배치, 출전 한도, 회복 아이템, 패배 후 재도전, 저장 복원을 확인합니다. 빌드 결과는 `dist/`에 생성됩니다.
