# 철령전기

철령전기는 React, Phaser 3, TypeScript, Vite로 만든 브라우저용 2D 턴제 전략게임입니다. 전장과 장수는 Phaser의 도형으로 그렸습니다.

## Windows에서 실행하기

가장 빠른 방법은 탐색기에서 `start-game.cmd`를 더블클릭하는 것입니다. 필요한 패키지를 처음 한 번 설치하고 브라우저를 엽니다.

VS Code에서 실행하려면 아래 순서로 진행합니다.

1. VS Code에서 **파일 → 폴더 열기**를 선택하고 이 README가 들어 있는 **iron-pass** 폴더를 엽니다.
2. **터미널 → 새 터미널**을 선택하고 아래 두 줄을 한 줄씩 실행합니다.

   ```powershell
   npm.cmd ci
   npm.cmd run dev
   ```

3. 터미널에 나온 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)을 브라우저에서 엽니다. 게임을 끝낼 때는 터미널에서 **Ctrl+C**를 누릅니다.

처음 실행할 때 Node.js 22.12 이상(22.x) 또는 24 이상이 필요합니다. 터미널에서 `node --version`으로 확인할 수 있습니다. Node.js가 없는 PC에서는 [Node.js 공식 다운로드](https://nodejs.org/en/download)에서 LTS 버전을 설치하고 VS Code를 다시 엽니다. `npm.cmd ci`는 처음 설치하거나 패키지 구성이 바뀌었을 때 실행합니다. 이후에는 `npm.cmd run dev`로 시작합니다.

## 스테이지 편집기

1. **`start-stage-editor.cmd`**를 더블클릭합니다. 편집기는 [127.0.0.1:5174](http://127.0.0.1:5174/stage-editor.html)에서 열립니다. 게임은 `start-game.cmd`로 따로 실행합니다.
2. 원정이나 시험 전투 목록에서 지도 하나를 선택합니다. 새로 만들거나 복제한 지도는 저장 후 게임 타이틀의 **시험 전투** 목록에서 선택할 수 있습니다. 기존 원정 지도를 선택하고 **프로젝트에 반영**하면 해당 원정의 다음 출전 또는 재도전부터 적용됩니다. 게임을 이미 켜 둔 경우 새로고침합니다.
3. 첫 아군 슬롯은 총대장 위치입니다. 일반 장수는 나머지 슬롯에 편성 순서대로 배치됩니다. 적군의 개별 AI는 전체 기본 AI보다 우선합니다. 현재 원정 데이터는 적 장비 설정을 지원하지 않습니다.
4. **초안 저장**은 이 브라우저에 편집 내용과 지도 시점을 저장합니다. **초안 복구**로 최근 초안을 다시 열 수 있습니다. **시험 전투**는 별도 창에서 편집 중인 지도를 실행합니다. **JSON 내보내기**로 지도 이미지가 포함된 파일을 만들어 다른 PC에서 가져올 수 있습니다.

프로젝트에 반영한 설정은 `stage-data/catalog.json`, 업로드 이미지는 `stage-data/images/`에 저장됩니다. 반영 전 목록은 `stage-data/backups/`에 남습니다. 프로젝트를 이전 상태로 복구하려면 게임과 편집기를 닫고 선택한 백업 JSON을 `stage-data/catalog.json`에 복사합니다. 특정 스테이지만 기본 지도로 돌아가려면 목록에서 해당 스테이지의 수정 항목을 제거합니다. 이미지 폴더는 이전 목록과 진행 중인 게임에서도 참조할 수 있으므로 함께 보관합니다.

## 첫 전투부터 상점까지

- **추천 편성 → 첫 전투 출전**을 누르면 장수 4명과 총대장 조조로 시작합니다. 직접 편성할 때는 코스트 10 안에서 장수를 선택한 뒤 총대장을 지정하세요.
- 지도에서 행동 전 장수를 선택하면 파란 이동 범위가 표시됩니다. 파란 칸 위에 마우스를 올리면 이동 경로가 나타납니다. 도착 칸을 클릭하거나 장수를 다시 클릭해 제자리에 머무르면, 붉은 공격 범위와 **공격·책략·도구·대기** 명령이 표시됩니다. **공격**은 범위 내 적에게 물리 공격을 하고, **책략**은 화계 같은 책략을 선택한 뒤 대상에게 사용합니다. **도구**는 보유한 회복 아이템을 보여 줍니다. 방향키와 Enter로 지도에서 칸을 고를 수 있고, Esc로 명령을 취소할 수 있습니다.
- 장수마다 턴당 한 번 이동할 수 있습니다. 공격, 화계, 회복 아이템, 대기 중 하나를 실행하면 해당 장수의 행동이 끝납니다. **아군 턴 종료**를 누르면 적군이 움직입니다.
- 적군을 모두 격파하면 **보상 받고 상점으로**를 누릅니다. 야영지에서 장수, 보물, 회복 아이템을 구매할 수 있습니다. 영입한 장수를 데려가거나 보물을 장착하려면 **출전 편성**을 엽니다. 준비를 마치면 **다음 전장 출전**을 누릅니다.
- 총대장이 쓰러지면 **같은 전장 재도전**으로 같은 맵과 적 배치에서 시작합니다. 출전과 재도전 때 병력은 최대치, 사기는 60으로 시작합니다. 살아 있는 부대의 사기는 새 턴마다 5씩 오르고 최대 100까지 쌓입니다. 증원은 합류할 때 사기 60으로 시작합니다. 전투에서 쓴 아이템은 소비됩니다.
- 진행 상황은 현재 브라우저에 자동 저장됩니다. 같은 주소에서 새로고침하거나 다시 열면 이어집니다.

## 원정 규칙

- 코스트는 최초 편성에만 적용합니다. 장수는 영입 인원 제한 없이 보유할 수 있고, 총대장을 포함해 최대 12명이 출전합니다. MVP에는 편성 및 영입이 가능한 장수 52명과 보물 24개가 있습니다.
- 각 전장의 맵과 적 편성은 고정되어 있습니다. 총 50개 전장이 10개 기본 지형의 변형과 고정 적 진형으로 구성되어 있습니다.
- 승리할 때마다 미영입 장수와 미보유 보물을 각각 최대 5개씩 무작위로 제시합니다. 후보가 5개보다 적으면 남은 후보를 모두 제시합니다. 이번 상점에서 구매한 자리는 다음 승리 때 새로 갱신됩니다.
- 보물은 장수당 하나를 장착할 수 있습니다. 회복 아이템은 전투 중에만 사용합니다.

## 장수 병과와 능력치

기존 웹 원정은 12개 임시 병종을 사용합니다. 신조조전 원정은 원본 병종 번호와 이름, 장수 배정, 성장치, 이동력, 공격 범위, 지형별 이동 비용과 능력치 배율을 사용합니다.

최초 편성, 상점, 출전 편성, 전투에서 아군의 무력·지력·통솔·정치를 볼 수 있습니다. 플레이 가능 아군의 능력치와 전법은 사용자 제공 삼국지8R PK 능력표를 기준으로 합니다. 사기는 전투 중 별도로 관리하는 수치이며, 책략과 전법에 사용합니다.

물리 기본 피해는 제공된 신조조전 7.0의 `ekd5.exe`에서 확인한 방식으로 계산합니다. 공격자 레벨 + 25에 보정 공격력과 방어력 차이의 절반을 더하며, 절반의 소수점은 0 방향으로 버립니다. 최소 피해는 1입니다. 물리 명중률에는 지형 보정이 적용된 순발력을 사용하고, 기본 반격 배율은 75%입니다.

공격력·방어력·순발력은 현재 장수 능력치, 레벨, 병종 성장치, 지형 보정으로 계산합니다. 기존 철령전기 공격·방어 보너스와 장착 보물의 수치도 사용합니다. 임시 지형 배율은 방패병이 일반 숲과 물에서 110%, 나머지는 100%입니다. 아군 레벨은 1이고, 적군은 10전장 단위로 1~5레벨을 사용합니다. 병종 상성, 방향·장비 특수효과, 피해 변동, 회심·2회 공격·책략은 7.0 원본과 대조가 더 필요합니다.

## 신조조전 원정

`iron-pass` 옆에 `jo` 폴더가 있으면 `start-game.cmd`가 최초 실행 때 원본 전장과 병종을 자동으로 가져옵니다. **추천 편성 → 첫 전투 출전**으로 영천 전투를 시작합니다. 화면 상단의 **기존 웹 원정**으로 기존 저장을 열 수 있습니다. 두 원정은 각각 자동 저장됩니다.

VS Code 터미널에서 가져오기를 다시 실행하려면 `npm.cmd run import:jo-game`을 사용합니다. 원본이 다른 곳에 있으면 `npm.cmd run import:jo-game -- "D:\Games\jo"`처럼 경로를 지정합니다. 전장, 병종, 불 지형 이미지를 가져오는 데에는 Node.js만 필요합니다. 화계나 열화로 불이 붙으면 불이 유지되는 동안 원본 불 지형 이미지가 표시됩니다.

원정에는 원본 순서의 첫 50개 지도, 지형, 출전 좌표와 적·우군 배치를 사용합니다. 총대장부터 원본 출전 칸에 배치하며 웹 출전 상한은 12명입니다. 영천 전투의 목표는 장보·장량 격파이며 유비·관우·장비가 2턴에 합류합니다. 다른 전장은 웹의 적 전멸 조건을 사용합니다. 원본 출전 위치가 같은 칸에 겹치면 한 유닛만 배치하며, 원본 각본상 아군 칸을 전부 적이 점유하는 사곡 전투에서는 인접한 빈 칸에 총대장을 배치합니다. 원본 책략·보물 효과와 나머지 이벤트는 후속 작업입니다.

## 개인 테스트용 그래픽

이 작업 폴더에서 개발 서버를 실행하면 `local-graphics/jo-assets`의 신조조전 초상화와 장수별 대기·이동·공격·피격 조형을 불러옵니다. 고유 조형이 지정되지 않은 유닛은 진영별 병과 조형으로 표시합니다. 대응 이미지가 없으면 기본 그래픽이 표시됩니다. 이 폴더는 개발 서버에서만 사용되며 배포 빌드와 프로젝트 ZIP에서는 제외됩니다.

다른 PC에서는 Git 저장소를 받은 뒤, 신조조전 7.0 원본 폴더를 `iron-pass` 옆에 `jo`라는 이름으로 둡니다. Python 3을 설치한 후 `iron-pass`에서 아래 명령을 실행하면 개인 테스트용 그래픽을 재생성합니다.

```powershell
python -m pip install "Pillow>=12"
npm.cmd run import:jo
```

원본 폴더가 다른 곳에 있으면 `npm.cmd run import:jo -- "D:\Games\jo"`처럼 경로를 지정합니다. 변환에 필요한 코드는 `tools/jo-assets`에 있습니다. 원본 파일과 변환 결과는 각 PC에 로컬로 보관합니다. 브라우저의 게임 진행 상태도 해당 PC에 저장됩니다.

## 개발 모드 시험 전투

`start-game.cmd` 또는 `npm.cmd run dev`로 실행한 뒤 **타이틀 → 시험 전투 → 원정 및 스테이지 → 사각판 시작 / 육각판 시작** 순서로 선택합니다. 스테이지는 원정 순서대로 표시됩니다. 신조조전 원정을 보려면 위의 원본 데이터 가져오기가 필요합니다. 영천은 두 버전이 있고, 목록 끝의 **육각 전장 시험 (9×7)**은 육각판으로 실행합니다.

시험 전투는 캠페인 저장을 읽어 편성하지 않고 추천 장수 조조·관우·하후연·곽가와 기본 장비로 시작합니다. 진행은 메모리에만 저장됩니다. **다시 시작**은 현재 전장을 처음부터 열고, **스테이지 선택으로**는 원정과 스테이지 선택을 유지한 채 목록으로 돌아갑니다. 승리와 패배도 시험 전투 화면에서 처리합니다.

### 영천 전투 비교

- 사각판은 20×20 원본 지도입니다. 육각판은 19×18에 북문, 서쪽 울타리 틈, 남문, 양옆 습지와 중앙 요새·병영을 재배치했습니다. 아래 좌표는 0부터 세는 `(열, 행)`입니다.
- 조조는 사각 `(7,0)`에서 육각 `(6,1)`로, 장보·장량은 `(9,11)·(10,11)`에서 `(8,11)·(9,11)`로 옮겼습니다. 북쪽 수비대 두 번째 부대는 `(10,6)`에서 문 안쪽 `(10,7)`로 옮겨 진입 칸을 열었습니다. 총대장과 나머지 아군, 적군, 증원 위치는 스테이지 데이터에 지정합니다.
- 시작 시 가장 가까운 아군과 북쪽 수비대 간 거리는 사각 7칸, 육각 5칸입니다. 해당 수비대를 일반 공격하는 위치까지의 최소 이동 비용은 조조가 6→4, 하후연이 4→3입니다. 같은 첫 수비병을 겨눈 난사는 사각판에서 옆의 두 번째 수비병도 맞히고, 육각판에서는 두 번째 수비병이 범위 밖에 있습니다.
- 시작 배치에서 바로 턴을 끝내면 첫 북쪽 수비병은 사각판에서 곽가를, 육각판에서 하후연을 공격합니다. 두 버전에서 유비·관우·장비가 2턴에 합류하며, 장보와 장량을 모두 격파하면 승리합니다.

### 육각판 조작과 규칙

- 9×7 시험 지도에서 평지는 이동 비용 1, 숲은 2입니다. 바위와 물은 통과할 수 없습니다. 시작 시 불붙은 칸은 **5열 6행**입니다. 원본 불 이미지가 있으면 배경을 제거한 불꽃 애니메이션을, 원본이 없으면 시험용 투명 애니메이션을 표시합니다.
- 9×7 지도에서 조조를 한 칸 오른쪽으로 이동해 화웅을 공격할 수 있습니다. **아군 턴 종료**를 누르면 적이 이동하고 공격합니다. 하후연의 사기가 70에 도달하면 **전법 → 난사**로 범위 안의 적 주변을 공격할 수 있습니다.
- 타일의 위에 꼭짓점이 오며, 0부터 세는 홀수 행이 오른쪽으로 반 칸 밀립니다. 위치는 기존과 같은 `{ x, y }` 열·행을 사용합니다. 좌우 방향키가 동·서를, `Q`·`E`·`Z`·`C`가 북서·북동·남서·남동을 선택합니다. 기존 스프라이트는 동·서에 좌우 모션, 북서·북동에 위쪽 모션, 남서·남동에 아래쪽 모션을 씁니다.
- 보병·기병 일반 공격은 인접 1칸, 궁병 일반 공격은 육각 거리 2칸까지입니다. 궁병 전법은 각 전법의 사거리를 사용하며, 원사는 축 방향 3칸까지 포함합니다. 화계 사거리는 육각 거리 3칸입니다. 기존 반격 조건은 육각 사거리를 적용해 판정합니다.
- 난사는 대상 칸과 그 주위 6칸, 난격·낙석은 공격자 기준 선택한 방향과 양옆의 3칸에 적용합니다. 열화는 여섯 축 중 한 방향의 1~2칸을 확인하고 지형에 맞는 칸에 적용합니다. 돌격은 같은 축을 최대 3칸 따라가며 통과 불가 지형 앞에서 멈춥니다. 맹돌로 밀리는 칸도 같은 축을 따릅니다.
- 격자 지정이 없는 캠페인 지도와 기존 세이브는 사각 격자로 열립니다.

### 육각판 스테이지 추가

`src/hex-stages.ts`의 `hexStageLayouts`에 원정 구분(`jo` 또는 `web`)과 스테이지 번호를 키로 추가합니다.

- `map`에 홀수 행이 오른쪽으로 밀리는 육각 타일 행을 작성합니다. `jo` 지도의 기호는 같은 파일의 `terrain`에서 원본 지형 번호로 변환합니다. 추가 지형의 색이나 그림은 `src/BattleMap.tsx`의 육각 지형 렌더링에서 지정할 수 있습니다.
- `deployment`, `enemies`, `guests`, `reinforcements`에 필요한 위치를 지정합니다. 키는 사각판 시작 좌표 `"열,행"`, 값은 육각판 좌표 `[열, 행]`입니다. 우군이나 증원이 있는 스테이지는 해당 그룹의 모든 좌표를 지정합니다. 시작 배치는 중복과 통행 불가 지형을 피하고, 주요 목표 주변까지 경로가 이어져야 합니다.
- 스테이지의 병력, 장비 설정, 장수 데이터, AI와 승리 조건은 기존 스테이지와 전투 초기화에서 가져옵니다. 등록된 육각판은 시험 전투 목록에서 바로 선택할 수 있습니다.

자동 테스트는 실제 첫 전투의 승리부터 구매와 2스테이지 출전까지, 초기 코스트, 50개 전장의 고정 배치, 출전 한도, 회복 아이템, 패배 후 재도전, 저장 복원을 확인합니다. 빌드 결과는 `dist/`에 생성됩니다.
